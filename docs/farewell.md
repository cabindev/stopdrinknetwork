# ส่งด้วยใจ (`/farewell`) — เครื่องมือวางแผนงานศพสำหรับครอบครัว

หน้าสาธารณะ ไม่ต้อง login ให้ครอบครัวที่เพิ่งสูญเสียวางแผนงานศพได้เอง พร้อมข้อมูลประกอบการตัดสินใจ
(สร้าง 2 ต.ค. 2026 · เมนู "ส่งด้วยใจ" ใน Navbar ทั้งเดสก์ท็อปและมือถือ)

## หน้า

| Route | ทำอะไร |
|---|---|
| `/farewell` | หน้าเปิด: ข้อความแสดงความเสียใจ, ปุ่มเริ่ม/ทำแผนต่อ, เครื่องมือ 4 อย่าง, ตัวเลขจากพื้นที่จริง |
| `/farewell/plan` | วางแผน 9 ขั้น: ชื่อ+ตำบล → จำนวนวัน → หีบ → อาหาร → ห่อกลับ → พระ → ดอกไม้ → เหล้า (+ข้อตกลงในพื้นที่) → งบประมาณ |
| `/farewell/plan/summary` | สรุปแผน + เช็กลิสต์ · พิมพ์ / Web Share / LINE / คัดลอก · ล้างข้อมูล |
| `/farewell/local` | ค้นข้อตกลงงานศพปลอดเหล้าในตำบล |
| `/farewell/signs` | ป้ายหน้างาน A4 แนวนอน 3 ข้อความ วาดลง canvas → PNG / พิมพ์ |
| `/farewell/journey` | 3D เลื่อนตาม "เส้นทางสุดท้าย" (ยกมาจาก `civicspace/app/last-journey`, three.js) |

## กติกาที่ต้องรักษา

- **สถิติการใช้แบบไม่ระบุตัวตน** (ผู้ใช้ตัดสินใจ 2 ต.ค. 2026 แบบที่ 1 — ยังไม่มีช่องขอความช่วยเหลือ): ตาราง `FarewellEvent`
  ส่งจาก `app/farewell/track.ts` → `POST /api/farewell/event` · เก็บแค่ ชนิดเหตุการณ์ + จังหวัด/ภาค + รหัสตัวเลือกในแผน + พบข้อตกลงไหม
  · **ห้ามส่งชื่อผู้วายชนม์/ตำบล/ราคา/IP** — API กรองเหลือเฉพาะค่าที่รู้จัก (enum, จังหวัดใน healthZones, รหัสตัวเลือกใน QUESTIONS)
  · กันนับซ้ำ: VISIT/PLAN_START/LOCAL_LOOKUP ครั้งเดียวต่อแท็บ (sessionStorage) · PLAN_COMPLETE ครั้งเดียวต่อแผน (localStorage,
    ล้างตอนกดลบแผน) · จำกัด 60 ครั้ง/10 นาทีต่อ IP (ในหน่วยความจำ) · เคารพ Do Not Track
  · แอดมินดูที่ `/dashboard/farewell` (เมนู "สถิติส่งด้วยใจ") — ยอดรวมเท่านั้น
  · ข้อความในหน้าเว็บบอกตรงตามจริง: ชื่อ/ตำบล/ตัวเลขอยู่ในเครื่อง เก็บแค่สถิติรวม — แก้สิ่งที่เก็บต้องแก้ข้อความด้วย
- **หน้า 3D (`/farewell/journey`) = สื่อรณรงค์สำหรับคนทั่วไป ไม่ใช่เครื่องมือของครอบครัว** (ผู้ใช้ตัดสินใจ 2 ต.ค. 2026):
  ไม่อยู่ในการ์ดเครื่องมือ/เมนูหลัก — ลิงก์เล็กท้าย /farewell + กล่อง "ส่งด้วยใจ" ในหน้ากรณีศึกษาเรื่องงานศพ
  (`stories/[id]`: ประเด็นย่อยงานศพปลอดเหล้า หรือชื่อเรื่องมี "งานศพ") + โพสต์โซเชียลของเพจ
- **ฟอนต์หัวข้อหน้า 3D = Kanit SemiBold** (SIL OFL, ไฟล์ + `Kanit-OFL.txt` ใน `journey/`) — แทน FC Vision (2 ต.ค. 2026):
  Fontcraft ให้ใช้ฟรีเฉพาะงานไม่เชิงพาณิชย์ และห้ามเผยแพร่ไฟล์ฟอนต์ (webfont = วางไฟล์ให้โหลดได้) · ใส่ฟอนต์ใหม่ต้องเป็น OFL หรือซื้อสิทธิ์แล้ว
- ไอคอน = ดอกไม้จันทน์ (`components/ChanFlowerIcon.tsx` วาดเอง สไตล์ lucide) ใช้ใน /farewell, Navbar, แดชบอร์ด
- **ข้อมูลแผนของครอบครัวอยู่ใน localStorage เท่านั้น** (`app/farewell/planStore.ts`, key `sdn-farewell-plan-v1`)
  แผนไม่ขึ้นเซิร์ฟเวอร์ (ผู้ใช้ตัดสินใจ ต.ค. 2026) — มีแค่สถิติไม่ระบุตัวตนด้านล่าง — ออกจากเครื่องเฉพาะตอนผู้ใช้กดส่ง/พิมพ์เอง
- **ไม่มีราคาตั้งต้นใด ๆ** ระบบยังไม่มีข้อมูลราคารายบรรทัด (กรณีศึกษาเองบอกว่าตัวเลข 2–3 แสนเป็นภาพรวม)
  ครอบครัวกรอกราคาที่ได้จากวัด/ร้านเอง ส่วน "ถ้าจัดวันเดียว/ถ้าไม่เลี้ยงเหล้า ลดได้เท่าไร" คำนวณจากตัวเลขของเขาเอง
- **"คุณไม่ได้เริ่มคนเดียว"** (`components/AgreementMapSection.tsx`, หน้า /farewell และต่อจากฉากสุดท้ายของ /farewell/journey):
  แผนที่ภาพนิ่ง SVG วาดฝั่ง server จาก `getAgreementMapData()` ทุกครั้ง (ผู้ใช้ขอ "แบบง่าย" — ไม่ใช้ Leaflet: ไม่ดักการเลื่อนหน้า
  ไม่โหลด tile และอัปเดตเองเมื่อมีพื้นที่ใหม่) · จุด = จุดกลางตำบล ไม่มีชื่อคน/สถานที่ · จุดของงานที่เผยแพร่แล้วกดไป /stories ได้
  · **ซูมพอดีกับจุดที่มีจริง** (ตอนนี้ = เหนือ + อีสาน ผู้ใช้ขอให้เห็นชัด) มีชุมชนภาคอื่นเพิ่ม กรอบขยายเอง · เส้นแบ่งจังหวัดจาง +
    ป้ายชื่อภาค (วางใต้กลุ่มจุดถ้าด้านบนไม่มีที่) · path เป็นพิกัดสัมพัทธ์ที่ปัดก่อนหาระยะ (กันเส้นเบี้ยว) + ลดความละเอียด
    เพราะ SVG ถูกส่งซ้ำทั้งใน HTML และ RSC payload
- **กล่อง "พื้นที่ของคุณมีข้อตกลงงานศพปลอดเหล้าแล้ว" เป็นสีเขียว** (ผู้ใช้ขอ — ข้อยกเว้นธีมเฉพาะสถานะพบข้อตกลง ห้ามลามไปส่วนอื่น)
- ตัวเลขแผนที่อัปเดตเอง: ทุกหน้า dynamic (layout อ่าน session) · นับงานประเด็นย่อย "งานศพปลอดเหล้า" ที่ติ๊กนโยบาย ≥1 ระดับ
  ไม่อยู่ในถังขยะ · ภาค = จาก region ของพื้นที่หลัก (north-* = เหนือ, northeast-* = อีสาน)
- **ตัด "น้ำยืน 990,000 บาท" ออกจากส่งด้วยใจทั้งหมด** (2 ต.ค. 2026 ผู้ใช้สั่ง — ตัวเลขยังไม่มีคนยืนยัน) อย่าใส่กลับ
- **ขั้นเหล้ามีตัวเลือก "เลี้ยงเหล้าเบียร์" ด้วย** (2 ต.ค. 2026) — เครื่องมือให้ข้อมูลประกอบการตัดสินใจ ไม่ชี้นำ
  ครอบครัวที่จะเลี้ยงต้องกรอกได้ตรงจริง (บรรทัดค่าเหล้าในงบขึ้นเมื่อเลือก "ยังไม่แน่ใจ" หรือ "เลี้ยง")
- ช่องค้นตำบลเตือนเมื่อชื่อซ้ำหลายแห่ง (เช่น หินดาด 3 แห่ง) — อย่าใช้ชื่อตำบลที่ซ้ำเป็นตัวอย่างใน placeholder
- เปลี่ยนขั้น = `window.scrollTo(0)` + โฟกัสหัวข้อขั้น (scrollIntoView แถบความคืบหน้า ทำให้หัวข้อหน้าโดน Navbar ลอยบัง)
- **ข้อเท็จจริงทุกข้อมาจากกรณีศึกษางานศพ Civic Space 2569** และแสดงที่มาใต้ข้อความ (`app/farewell/content.ts`) ห้ามแต่งเพิ่ม
- **ข้อตกลงในพื้นที่** (`app/lib/farewellAgreements.ts`): งานประเด็นย่อย "งานศพปลอดเหล้า" + `ActivityPolicy`
  เปิดเผยระดับเดียวกับแผนที่โหมดสาธารณะ: ชื่องาน + ตำบล/อำเภอ/จังหวัด + ระดับ/ประเภท/ปีของข้อตกลง
  **ชื่อนโยบายเปิดเฉพาะงานที่เผยแพร่แล้ว** (เหมือน `STORY_SELECT`) · ไม่มีผู้ประสานงาน/พิกัด/ชื่อสถานที่
  · "ครอบคลุมพื้นที่" = ตำบลเดียวกัน, ข้อตกลงระดับอำเภอในอำเภอเดียวกัน, หรือระดับจังหวัด
- API สาธารณะ: `/api/farewell/area?q=` (ค้นตำบลจาก regions.ts ไม่แตะ DB/GISTDA) ·
  `/api/farewell/agreements?district=&amphoe=&province=` (รับเฉพาะตำบลที่มีจริงใน regions.ts)
- ธีม: ส้ม–ขาว–ดำ พื้นล้วน ไม่มี gradient ใน UI (texture ใน 3D ใช้ gradient วาดคราบเขม่าได้ เพราะเป็นภาพ ไม่ใช่ UI)
- Navbar ซ่อนตอนพิมพ์ (`print:hidden`) เพื่อให้สรุปแผน/ป้ายพิมพ์ออกมาสะอาด

## ทดสอบ

ทดสอบด้วย headless browser (2 ต.ค. 2026): ไล่วางแผนครบทุกขั้นที่ 390×844, ตำบลหินดาด อ.ห้วยแถลง
ขึ้น "พื้นที่ของคุณมีข้อตกลงงานศพปลอดเหล้าแล้ว", งบ 3 วัน (อาหาร 8,000 + พระ 3,000 + เหล้า 5,000 ต่อวัน)
แสดงลดได้ 32,000 ถ้าวันเดียว และ 15,000 ถ้าไม่เลี้ยงเหล้า, ป้ายดึงชื่อจากแผน, 3D โหลดได้ทั้งมือถือและเดสก์ท็อป
